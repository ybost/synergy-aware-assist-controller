# Synergy-Aware Assist Controller

A simulation-based rehabilitation-robotics project: detecting and compensating for
shoulder-abduction-dependent elbow-flexion coupling during planar reaching.

Status: in development. See the project charter in `docs/` for scope and claims.

## Layout

- `src/synergy_aware/` - simulator, impairment model, controllers, estimator
- `tests/` - verification and validation tests
- `docs/` - charter, specifications and write-ups
- `notebooks/` - exploratory analysis
- `scripts/` - experiment entry points
- `results/` - final figures
